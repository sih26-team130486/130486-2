# Hackathon Demo Flow

1. Login with demo credentials.
2. Review dashboard.
3. Open `CASE-2026-001`.
4. Upload an FIR or sample document.
5. Show SHA-256 hash and registration.
6. Open document viewer and metadata.
7. Run integrity verification.
8. Register/open evidence `EV-0001`.
9. Open chain of custody.
10. Create a custody transfer request.
11. Open OCR / PII detection / redaction.
12. Ask Pramaan AI to summarize or explain custody.
13. Open Court Export.
14. Generate a real ZIP package and evidence certificate.
15. Review audit logs and security alerts.
16. Open Offline Center and Sync Center.
17. Finish on System Health to show integration-ready adapters.
