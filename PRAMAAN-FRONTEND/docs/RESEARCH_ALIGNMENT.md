# PRAMAAN Research Alignment

This frontend update incorporates the innovation directions from the supplied SIH26190 research note while keeping production-only claims clearly marked as prototype/integration-ready.

Implemented as frontend/local demonstrations:
- Blind compliance / zero-knowledge proof artifact generation.
- Dynamic trace metadata demonstration for document views/downloads.
- Post-quantum readiness artifact referencing CRYSTALS-Kyber and Dilithium.
- Electronic-record certificate artifact aligned to the Bharatiya Sakshya Adhiniyam, 2023 concept.
- Context-aware PII/redaction workflow already present in the prototype.
- Dual-key / 2-of-2 custody approval simulation.
- CCTNS / ICJS mapping artifact with e-Courts/e-Prisons-ready references.
- Offline-first local vault and synchronization workflow.
- Live tamper/breach simulation that creates a hash-mismatch alert and blocks simulated admission.

Production boundary:
The browser-only prototype does not claim to implement production zk-SNARK circuits, invisible steganographic embedding, production post-quantum cryptography, government identity integration, or legally valid court certification. Those require backend/authorized infrastructure.
